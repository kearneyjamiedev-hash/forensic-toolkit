Analysis results

File identification

Signature analysis

Compares the filename extension with the detected file structure and signature.

Integrity

Cryptographic hashes

SHA-256 is used as the primary evidence integrity hash. Re-select the file later to verify that it still matches the original analysis.

Filesystem context

Evidence copy

Filesystem information associated with the copy currently being analysed.

Timeline

Forensic timeline

Timestamps from filesystem and embedded metadata are collected into a common chronological view. UTC conversion is only performed where timezone information is available.

Extracted content

Interesting artefacts

Readable strings are inspected for values that may be useful during an investigation. Their presence does not imply malicious activity.

Format analysis

File structure

Format-specific structural analysis is performed without opening or executing the analysed file.

Metadata

Extracted metadata

Metadata is grouped by source and type to help distinguish filesystem, document, image and application information.

Reports

Export analysis

Export the persisted analysis in machine-readable or human-readable formats. Reports retain the original SHA-256 evidence baseline.

The HTML report is a standalone human-readable forensic report. JSON retains the complete structured analysis, while the CSV exports provide focused timeline and artefact datasets.
